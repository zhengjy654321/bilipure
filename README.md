# 柠檬课堂 · BiliPure

Android 平板 WebView 学习应用。应用内使用 B站网页播放器，注入专注界面和学习进度；不需要 X 浏览器或油猴。

## 功能
- 指定 UP 主课程主页，预置橘子zhen好吃；添加课程和自定义合集。
- 合集/视频/分 P 三层进度，小柠檬动画；拖动播放位置同步、回退恢复、手动固定。
- 完整、迷你和折叠面板；拖动记忆位置，不挤动原网页。
- 合集与视频排序、删除、批量移动/复制；UP 主投稿分页勾选添加。
- 保留官方选集和播放控制，清理推荐、广告和评论。
- 应用内网页登录、视频全屏、返回导航、JSON 进度导入/导出。
- 全屏右侧常驻后退 15 秒／前进 15 秒按钮，跳转同步三个学习进度，自动限制在当前分 P 范围。

## 下载测试 APK
在本仓库 Actions 中打开成功的 **Build Android APK**，下载 **bilipure-apk**，解压安装 `.apk`。Android 8.0 以上，需要较新的 Android System WebView。

首次使用先进入“官方登录／页面”登录 B站。旧脚本中导出 JSON，在应用课堂面板的“导入进度”选择文件迁移。登录状态不与外部浏览器共享。

## 构建
GitHub Actions 使用 JDK 17、Gradle 8.11.1、Android Gradle Plugin 8.9.2、Android SDK 35。推送 main 或手动运行 workflow 会执行 JS 语法检查、Android 编译和 lint，产出测试 APK 及 SHA256 校验值。

本项目当前是 **debug 签名的测试版**。不同 Actions 构建机器生成的测试签名可能不同，后续覆盖安装可能需要先备份进度再卸载旧版。正式发行前应将稳定签名密钥配置到 GitHub Actions Secrets，不能把发行密钥提交进仓库。

## 权限与边界
只声明网络权限，不需要“所有文件访问”、摄像头或麦克风。导入导出通过系统文件选择器。进度存在应用私有存储，不上传第三方；卸载前请备份。

原生消息桥只允许两个明确的 B站主页面源，拒绝 iframe 请求；网络桥只允许三个 B站资料 API 的 HTTPS GET，不跟随重定向，不暴露读取 Cookie 的接口。TLS 错误不放行，禁用 file:// 文件访问，外站链接需确认后交给系统浏览器。

这是独立学习工具，并非哔哩哔哩官方客户端。内容、登录、画质与播放权限由 B站原页面决定；UP 主列表请求可能受接口风控影响。广告选择器、全屏、弹幕与登录需要在目标平板实测，WebView 打包本身不会解除站点限制。全屏时面板移入播放器全屏层，三种形态保持可用；普通模式与全屏模式分别记忆拖动位置。直接对 video 的全屏请求转到播放器容器，避免进入仅显示视频的原生画面。此逻辑已通过模拟 DOM 回归测试，仍需目标平板验证 WebView 实际表现。

## 0.2 平板触摸更新
单击画面显示/隐藏控制栏，双击暂停/继续；横滑整幅画面仅调整 60 秒，预览后松手跳转，可反向微调。按住 450ms 临时使用至少 2× 播放，松手、取消、切后台或换播放器恢复原倍速。画质/设置入口可临时返回官方控制，完成后点“返回触摸操作”。全屏 ±15 秒按钮及三态进度面板保留。
应用使用系统栏与挖孔安全边距，即使全屏隐藏系统栏仍预留操作空间；键盘弹出时按实际高度避让。已做触摸事件模拟回归测试，实机手感仍需平板验证。

## 0.3 修复与柠檬主题
官方设置与触摸控制采用互斥模式，暂停和延迟点击不再唤醒自制栏。弹幕按钮优先点击真实 checkbox，支持播放器外的发送栏，展示官方开关的实时状态；无法定位时明确显示未就绪。应用名称、启动图标、主页、六个进度动画及导出文件名改为柠檬，UP 主姓名、视频资料和用户自定义标题不替换。旧进度存储键与导入格式兼容。

## 0.4 学习目标
主页、完整面板和半开面板都可设置/编辑一个当前目标：合集、视频、分 P、分秒，以及本地日期和完成时间。从所选合集当前播放位置起，按目录顺序计算视频时长；先扣除 300 秒缓冲计算所需倍速，≤1.5× 显示“完成可能性较高”。
半开面板保留原三层进度，并增加自己的目标完成度和小柠檬同学进度、当前追赶倍速、暂停剩余时间及落后提醒。小柠檬按保存目标时确定的匀速前进，暂停/缓冲/切后台/切到其他合集累计免走最多 300 秒，超出后继续走。更改倍速不改变它的匀速；拖动视频会改变自己的完成度。应到位置显示分 P 和时间，完整视频名可查看提示。
编辑保存会从当前播放位置重新规划并重置该计划缓冲，删除目标不改课程进度。目标随 JSON 备份导入导出，重开应用会结算离开期间的暂停；截止时间后计划同学不再继续前进。合集目录更改时提示编辑目标，避免按变化后的顺序计算错误距离。至少需留出 5 分钟以上的截止时间；不提供后台通知。
